# Task 2 — To-Do List Web App

A responsive front-end To-Do List application built using only HTML, CSS and Vanilla JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter All / Active / Completed
- Clear completed tasks
- Task counter and completion progress
- Responsive design for mobile, tablet and desktop
- LocalStorage persistence
- No page reload required for UI updates

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in Chrome.
